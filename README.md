# Приставки Xiaomi TV: чистка и лёгкий лаунчер

Всё, что мы сделали с двумя приставками по методике [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv): отключение мусора через ADB и замена главного экрана на лёгкий лаунчер. Дата работ: 2026-10-31.

## Структура папки

- `boxes/`: заметки по каждой приставке (что отключено, что оставлено, как откатить).
- `backups/`: списки пакетов до чистки. Нужны для отката.
- `launcher/`: собранный APK лаунчера, патч конфига, команды отката, хэш и версия исходников.
- `screenshots/`: скриншоты главного экрана с приставок.

## Подключение по ADB

1. На приставке включить режим разработчика и отладку по сети.
2. `adb connect <ip>:5555`, на экране приставки подтвердить «Всегда разрешать».
3. Если порт не 5555 и подключение не идёт, это беспроводная отладка: нужен `adb pair`.
4. IP может смениться, если роутер раздаёт адреса динамически. Лучше закрепить за приставками постоянные адреса.

## Что делали (кратко)

1. Прочитали репо cleanyourtv и проверили код лаунчера: нет разрешения INTERNET, нет запуска процессов и загрузки кода, зависимости только от Google.
2. Сняли списки пакетов (бэкап), отключили телеметрию, рекламу, контент Xiaomi и ненужные приложения через `pm disable-user --user 0`.
3. Собрали лаунчер в Docker (JDK 17, Android SDK 34), поставили на обе приставки.
4. Включили службу `HomeKeyService`: она перехватывает кнопку Home и открывает новый лаунчер, а Google TV Launcher остаётся включённым (в репо есть случай чёрного экрана после отключения `launcherx`).

Приложения, которыми пользуются владельцы: YouTube, VK Видео, Кинопоиск, HDRezka, SASFlix, VLC (ivi и Okko пока не установлены).

## Откат

Команды в [launcher/restore.txt](launcher/restore.txt). Один отключённый пакет возвращается так:

```bash
adb -s <ip>:5555 shell pm enable <пакет>
```

Список того, что было отключено до нас и что мы отключили, смотрите в `boxes/`.

## Известные нюансы

- Сборка Gradle в Docker на этом интернете идёт очень медленно и падает на скачивании зависимостей. См. [launcher/README.md](launcher/README.md), как собрать повторно.
- После переустановки APK служба доступности выключается, надо включить снова.
- `WRITE_SECURE_SETTINGS` лаунчеру не выдавали. При принудительной остановке лаунчера служба Home может отключиться.
- Netflix (`com.netflix.ninja`) на приставке 1 был отключён ещё до нас.
